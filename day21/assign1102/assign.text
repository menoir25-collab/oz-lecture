01.
ⓐ 다른 파일에서 쓸 수 있도록 함수 · 변수를 내보내는 말 :export
ⓑ 파일에 하나만 두는 기본 내보내기 — 가져올 때 중괄호 없이 이름을 정함 :export default
ⓒ 다른 파일이 내보낸 것을 가져오는 말 :import
ⓓ import가 있는 파일을 불러올 때 script 태그에 넣는 속성 :type="module"
ⓔ 패키지를 설치 · 업데이트 · 삭제하는 Node.js 패키지 관리 도구: npm
ⓕ 프로젝트 정보와 쓰는 패키지가 적힌, 프로젝트의 이름표 파일 :package json
ⓖ 최종 제품에서 쓰는 패키지가 적히는 칸 :dependencies
ⓗ 개발 · 테스트할 때만 쓰는 패키지가 적히는 칸 :devDependency
ⓘ 실제로 받은 정확한 판을 적어 두는 파일 :packageplock json

04.
ⓐ 화면을 만드는 데 쓰는 react가 적힌 칸의 이름 : dependencies
ⓑ 빌드 도구 vite가 적힌 칸의 이름 : devDependencies
ⓒ dayjs에 적힌 ^1.11.23의 범위에 드는 판은 1.12.0과 2.0.0 가운데 어느 것인가 : 1.12.0
ⓓ dayjs를 ~1.11.23으로 적으면 범위에 드는 판은 1.11.24와 1.12.0 가운데 어느 것인가 :1.11.24
ⓔ 호환되는 버그 수정만 한 판이 나올 때 올라가는 자리의 이름(MAJOR · MINOR · PATCH) : patch
